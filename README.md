# Blinkit Sales Analysis – Interactive Power BI Dashboard


## 1. Project Overview

This project focuses on analysing Blinkit's sales performance and business operations through an interactive Power BI dashboard.

The dashboard provides insights into sales trends, product categories, outlet performance, customer ratings, and item characteristics. It transforms raw sales data into meaningful visualisations and key performance indicators (KPIs) to support data-driven business decisions.

The project demonstrates the practical application of data visualisation, business intelligence, and analytical techniques using Microsoft Power BI.

## 2. Project Objectives

- Analyse overall sales performance and key business metrics.
- Evaluate sales distribution across different product categories.
- Identify the impact of fat content on total sales.
- Compare outlet performance based on location and size.
- Analyse sales trends across different outlet establishment years.
- Evaluate customer ratings and average sales performance.
- Develop an interactive dashboard for effective business analysis.

## 3. Key Dashboard Features

**Sales Performance Analysis**
- Total Sales.

**Product Category Analysis**

**Outlet Performance Analysis**
- Sales by Outlet Location.
- Sales by Outlet Size.
- Sales by Outlet Establishment Year.

**Interactive Dashboard**
- Dynamic KPI selection.
